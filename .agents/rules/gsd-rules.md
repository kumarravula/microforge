# Workspace Execution Rules (GSD Protocol)

1. **Verify Before Declaring Success**: Always run tests or compile code before concluding a task.
2. **Atomic Commits**: Stage and commit logical increments rather than massive unorganized changes.
3. **Spec Adherence**: Follow specifications laid out in `tasks.md` and `PRD.md`.
4. **Preserve Documentation**: Keep all comments, docstrings, and license headers intact unless explicitly modified.
